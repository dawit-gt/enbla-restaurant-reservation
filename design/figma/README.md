# Figma Folder

This folder contains Figma design assets for the Enbla Restaurant Reservation app.

## Contents

- Figma design files (.fig or links)
- Exported UI screens (PNG, JPG, SVG)
- Design system documentation (colors, typography, components)
- User flows and wireframes
- Notes on design decisions

## How to Use

Open the Figma files in Figma or view exported images for reference. See documentation for design guidelines.
